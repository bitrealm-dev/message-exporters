# message-vault-client

Push a Message Exporters **JSONL** export folder into [Message Vault](https://github.com/bitrealm-dev/message-vault-rs).

- Library: `message_vault_client::run`
- CLI: `vault-push` (`--features cli`)
- GUI: Message Exporters → **Vault** tab

See [docs/MANPAGE.md](docs/MANPAGE.md).
